# Security Policy / Política de seguridad

## Reporting a vulnerability / Reportar una vulnerabilidad

If you find a security issue in NetPwn itself (not in the networks it tests),
please report it responsibly:

- Open a private security advisory on GitHub
  (**Security → Report a vulnerability**), or
- Email the maintainer via the GitHub profile.

Please do **not** open public issues with exploitable details. We aim to
respond within 72 hours.

Si encuentras un problema de seguridad en el propio NetPwn (no en las redes
que prueba), repórtalo de forma responsable mediante el asesor privado de
seguridad de GitHub. No abras issues públicas con detalles explotables.
